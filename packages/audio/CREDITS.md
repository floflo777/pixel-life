# @pl/audio: credits and provenance

Every sound in this package is **synthesized at runtime from code**. The package contains no
recordings, samples, soundfonts or third-party audio files, and it downloads none at runtime.

| Asset                                         | Source                                                                                                        | Licence                      | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| All SFX cues (`src/cues.ts`)                  | Original patches written for Pixel Life, rendered by `src/synth/render.ts`                                    | Apache-2.0 (this repository) | Sine/triangle oscillators, FM, and filtered white noise from a seeded xorshift generator.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Music instruments and themes (`src/music/**`) | Original generative composition code for Pixel Life                                                           | Apache-2.0 (this repository) | Bars are derived from the seed, so no composed audio is stored.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Palette and motifs                            | Adapted from the FriendSDK sound kit (`@rarefriends/friendsdk` 0.1.4, `src/friend-sounds.ts`, `SOUND_KIT.md`) | Apache-2.0 (FriendSDK)       | We reuse the kit's _style_: its rounded sine + triangle "chip" pluck envelope (sin² attack/release, exponential decay), the soft band-passed noise tick, and its C-major pickup motifs (`select` → `ui.click`, `purchase` → `ui.confirm`, `reveal-legendary` → the base of `gold.reveal`). No code is copied verbatim; the formulas are reimplemented in `src/synth/render.ts` and `src/synth/builders.ts`. The SDK's own provenance is recorded in `node_modules/@rarefriends/friendsdk/assets/sound-provenance.json`. |

The design direction comes from `docs/design/gdd.md` §8 (audio direction and SFX list) and the art
bible's motion and tone rules.

If a CC0 recording is ever added, list it here with its source URL, author, licence text and SHA-256
before merging.
